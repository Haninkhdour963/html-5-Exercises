# html-5-Exercises
Orange Coding Academy — HTML Exercises (Basic → Advanced)
One-line description: A complete, well-organized collection of HTML exercises from Orange Coding Academy — starting with fundamentals and progressing to advanced projects — ready for study, practice, and demonstration.

Overview
This repository collects all HTML exercises from Orange Coding Academy, arranged by level (Basic → Intermediate → Advanced). Each exercise is a small, self-contained folder with an index.html (and assets) plus a short README describing goals, hints, and learning outcomes.

Use this repo to:

practice real-world HTML structure and semantics,

build a portfolio with progressive projects,

prepare for interviews or coursework.
